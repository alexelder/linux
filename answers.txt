== Question 12

The issue is that callers of do_read_data() and do_save_data() need to enforce
mutual exclusion against not just callers of the same function but also callers
of ther other function in the pair.  In other words, the critical section of
do_read_data() cannot run concurrently with the critical section of
do_save_data(), and vice versa.

By using one spin lock for both functions, exclusion is enforced across both
functions rather than among calls to each specific function, as would be the
case if each function used its own spin lock to protect its critical section.

== Question 13

No, it is not safe to hold a spin lock when calling copy_to_user(). The copy
function might block (for example, if a page fault is encountered), and blocking
is not allowed while holding a spin lock.
